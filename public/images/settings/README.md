# Settings preference icons

The heart (16 × 16), map pin (16 × 16), and arrow (24 × 24) are local,
unchanged SVG exports from the [SC2006 Settings V4 frame](https://www.figma.com/design/PBywTYV9pSSJQwVkQOy1tx/SC2006?node-id=2117-13896).
They retain their native dimensions inside responsive preference tiles.

The shell reuses the existing court photograph and navigation icons. Profile
details and account actions are rendered as accessible text and controls rather
than the flattened screenshots embedded in the reference. The design's sample
name, preferences, and activity figures are not application data.
